# Restioo – Ngủ Trưa Thông Minh 🌙

Restioo là một ứng dụng web hiện đại được thiết kế để giúp người dùng quản lý và tối ưu hóa giấc ngủ trưa của họ. Ứng dụng cung cấp giao diện thân thiện, trực quan với các tính năng hỗ trợ người dùng có một giấc ngủ trưa chất lượng cao.

## ✨ Tính Năng Chính

- **Giao diện hiện đại**: Thiết kế đẹp mắt với gradient màu xanh đại dương độc đáo
- **Responsive Design**: Hoạt động tốt trên tất cả các thiết bị (desktop, tablet, mobile)
- **Hiệu ứng Animation**: Các hiệu ứng động mượt mà để tăng trải nghiệm người dùng
- **Tối ưu hiệu suất**: Sử dụng CSS Grid Pattern và Backdrop Filter cho hiệu ứng kính mờ
- **Hỗ trợ Tiếng Việt**: Giao diện hoàn toàn bằng tiếng Việt

## 🚀 Công Nghệ Sử Dụng

- **HTML5**: Cấu trúc markup ngữ nghĩa
- **CSS3**: Styling hiện đại với gradient, animation, và backdrop filter
- **Tailwind CSS**: Framework CSS tiện ích (v3.4.17)
- **JavaScript**: Tương tác và xử lý logic
- **Lucide Icons**: Thư viện biểu tượng SVG (v0.263.0)
- **Google Fonts**: Phông chữ "Be Vietnam Pro" và "Playfair Display"

## 📋 Yêu Cầu

- Trình duyệt web hiện đại hỗ trợ:
  - CSS Grid
  - Flexbox
  - CSS Animation
  - Backdrop Filter
  - CSS Custom Properties (Variables)
- Kết nối Internet (để tải CDN resources)

- **Primary (--primary)**: `#1E6B8A` - Xanh chính
- **Accent (--accent)**: `#5BBFD6` - Xanh nhấn
